# Accepted product design and implementation references

M02 design specifications and the accepted M04 website provide the design baseline. The owner selected Option 3 for public pages and Option 2's structured information architecture for authenticated workspaces, with one consistent design system. Actual application code lives in [apps/web](../apps/web/README.md); these references do not establish runtime availability.

| Folder | Responsibility |
| --- | --- |
| `ui-ux/` | Utility, resident and field workflow references. |
| `wireframes/` | [M02 page and wireframe specifications](wireframes/PAGE_AND_WIREFRAME_SPECIFICATIONS.md); proposed designs remain distinct from implemented routes. |
| `design-system/` | [Shared UI guidance](design-system/UI_UX_DESIGN_SYSTEM.md). |

Use the [current capability map](../apps/web/src/lib/route-capabilities.json) and [completion register](../docs/testing/PRE_M10_COMPLETION_REGISTER.md) for actual delivered behavior. Automated accessibility and responsive checks do not replace native zoom or manual assistive-technology acceptance. Physical evidence, media, privacy and deployment gates remain explicit.
