Its official source distribution was installed with `DISABLE_SQLALCHEMY_CEXT=1`, producing the supported pure-Python build at the same version. Other packages imported successfully; no interpreter packages were copied or machine policy changed. `pip check` passed. Windows setup must preserve this supported installation option.
- Docker/Compose/PostgreSQL are absent on this Windows host. Use official EDB PostgreSQL 17.11 binaries and OSGeo PostGIS 3.6.2 in an isolated workspace, loopback listener, dedicated disposable databases and separate migration/runtime identities. PostGIS 3.6 replaces the conservative 3.5 recommendation only as a compatible maintained extension, without changing geometry or application contracts. Container checks remain NOT TESTED until actually executed.
- Reviewed M02 remains the canonical final field and API catalogue. Static, reviewable Alembic SQL migrations implement the selected operational subset. Future nullable references are CHECK-guarded NULL; remove each guard only after its real parent and same-tenant FK exist. No runtime ORM generation from the catalogue.
- Requests use Pydantic 2 and authoritative JSON Schema validation; responses are checked against the same canonical wire schemas. Runtime OpenAPI exposes implemented operations only. The traceability matrix records all 117 target operations.
- Database RLS is defense in depth with transaction-local context and a non-owner, NOBYPASSRLS runtime principal. Restricted global authentication repositories are separate from tenant queries. Global membership discovery uses a narrowly scoped database function; no request header selects a trusted tenant.
- Private development auth delivery is a bounded, post-commit local adapter, with no public token retrieval route. External delivery, public deployment, device ingestion, simulation jobs and uploads remain disabled.
- Internal liveness/readiness are separate infrastructure routes under /internal/health; HTTPS proxy denies them externally. Readiness checks database access, runtime-role safety and migration head with a short timeout and no diagnostic secrets in responses.
